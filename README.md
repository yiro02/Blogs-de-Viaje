# 🌍 Blogs de Viajes

**Sitio en vivo:** [https://blogs-viajes.netlify.app](https://blogs-viajes.netlify.app)

Bienvenido a **Blogs de Viajes**, un sitio donde exploradores, mochileros y amantes de la aventura pueden leer y compartir experiencias de viaje por todo el mundo. Desde guías prácticas hasta relatos inspiradores, este blog está hecho para despertar tu espíritu viajero.

---

## ✨ Características

- 📝 Publicaciones de blog con historias reales de viajes
- 📸 Imágenes atractivas y contenido visual
- 📱 Diseño responsive y optimizado para móviles
- 🔍 Navegación fluida entre entradas
- 📄 Descarga de archivos como currículums (PDF) directamente desde la interfaz
- 🚀 Desplegado en [Netlify](https://netlify.com)

---
## 🛠️ Tecnologías utilizadas
- 👌👌👌 solo para personas Interesados.
- **HTML5 & CSS3**
